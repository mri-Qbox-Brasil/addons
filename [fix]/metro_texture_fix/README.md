# Mapas, Props e Otimizações — New Age Studios

Este repositório reúne mapas, props e otimizações desenvolvidos pela **New Age Studios** especialmente para a **MRI QBOX**.

O objetivo deste projeto é melhorar a qualidade visual, a organização e o desempenho dos recursos utilizados no servidor, mantendo uma experiência mais estável e otimizada para os jogadores.

## Conteúdo do projeto

Este pacote pode incluir:

- Mapas personalizados;
- Props exclusivos;
- Correções de posicionamento;
- Ajustes de colisão;
- Remoção de objetos desnecessários;
- Otimizações de texturas e modelos;
- Redução de consumo de memória;
- Melhorias de desempenho;
- Organização de arquivos e recursos;
- Ajustes específicos para o ecossistema MRI QBOX.

## Otimizações

As otimizações realizadas pela New Age Studios têm como foco:

- Reduzir impactos no FPS;
- Diminuir o uso excessivo de memória;
- Evitar objetos duplicados;
- Melhorar o carregamento dos mapas;
- Corrigir colisões e falhas visuais;
- Manter compatibilidade com os recursos utilizados pela MRI QBOX.

## Instalação

1. Faça o download ou clone este repositório.
2. Coloque a pasta do recurso dentro da pasta `resources` do seu servidor.
3. Adicione o recurso ao arquivo `server.cfg`.

```cfg
ensure nome_do_recurso
```

4. Reinicie o servidor ou inicie o recurso pelo console.

> Altere `nome_do_recurso` para o nome correto da pasta adicionada ao servidor.

## Requisitos

- Servidor FiveM atualizado;
- Artefatos recomendados atualizados;
- Estrutura configurada para MRI QBOX;
- Dependências específicas informadas dentro de cada recurso, quando necessário.
