# K9addon

Ped addon de cachorro K9 (`a_c_k9`), pastor alemão / malinois com as variações de acessório, cabeça e corpo.

## Créditos

- Modelo original: [German Shepherd / Malinois K9 Dog](https://www.lcpdfr.com/downloads/gta5mods/character/19996-german-shepherd-malinois-k9-dog/), de martinct (Mouby).
- Conversão para ped addon: [Popcorn RP](https://github.com/alberttheprince/popcornrp-pets) (`K9addonoriginal` do popcornrp-pets).
- Texturas otimizadas pela [New Age Studios](https://www.newageoficial.com/): o resource caiu de 68,5 MB para 14,6 MB sem mudar o modelo.
