# K9addon

Ped addon de cachorro K9 (`a_c_k9`), com as variações de acessório, cabeça e corpo.

As texturas foram otimizadas pela [New Age Studios](https://www.newageoficial.com/): o resource caiu de 68,5 MB para 14,6 MB sem mudar o modelo.

O modelo e as texturas originais são dos criadores do mod. Se você é o autor e quer crédito ou remoção, abra uma issue.
